## 🚀 Proyectos Destacados

### 🧭 [ArtemisApp](#)
Plataforma integral para gestión académica y revisión de conceptos jurídicos en tiempo real.  
**Stack:** Next.js, Prisma, Supabase, Redis, TypeScript  
**Características:**
- Autenticación con NextAuth  
- Actualizaciones en tiempo real  
- Panel administrativo dinámico  
- Sistema de notificaciones inteligente  

### 💬 [ChatConnect](#)
Aplicación de chat en tiempo real con canales y usuarios autenticados.  
**Stack:** Node.js, WebSocket, React, PostgreSQL  
**Características:** Autenticación JWT, persistencia de mensajes y manejo de eventos en vivo.
